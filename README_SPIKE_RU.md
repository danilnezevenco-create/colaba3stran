# SPIKE для squadmc / SBW 0.8.8

Архив содержит исходники для твоего существующего проекта `colaba3stran`
(Minecraft 1.20.1, Forge, Java 17). Его содержимое нужно добавить в проект
и собрать `squadmc`. Сам ZIP в папку `mods` не устанавливается.

## Что добавлено

- Предмет `squadmc:spike` с названием **SPIKE** во вкладке `squadmc`.
- Модель, текстуры, анимации, звуки и изображение экрана Javelin из установленного SBW.
- Выстрел из прицела без захвата техники: нужно непрерывно удерживать **ЛКМ 2 секунды** (40 серверных тиков при 20 TPS). Отпускание ЛКМ до выстрела сбрасывает подготовку. Одно удержание даёт один выстрел.
- Во время подготовки в нижней части окна прицела, на месте красной отметки из скриншота, появляется жёлтое **SEEK** с белой обводкой. Это индикатор подготовки, захвата цели нет.
- Наведение переделано по принципу ПТУРа SBW и `MalyutkaEntity`: ракета плавно следует линии прицеливания, без преследования скачущей точки пересечения с блоком или сущностью. Небольшой подъём после старта постепенно исчезает; высокий подъём до 32 блоков убран.
- При выходе из прицела связь с уже выпущенной ракетой обрывается окончательно. Она сохраняет последнюю скорость и направление; повторный вход в прицел её не перехватывает.
- Прямой урон **1000** одной задетой сущности. Радиус взрыва и взрывной урон отсутствуют; ракета не разрушает блоки.

Используется отдельный тип урона `squadmc:spike_hit`: обычная броня Minecraft
и стандартные коэффициенты защиты техники SBW его не уменьшают. Защита
творческого режима и сторонние правила запрета урона сохраняются.
Собственное поведение уничтоженной техники определяется её модом.

## Установка исходников

1. Скопируй папку `src` из архива в корень **существующего** проекта, где находятся
   `build.gradle` и `gradlew.bat`. Объедини папки, сохранив остальные файлы проекта.
2. Из существующих файлов изменены только:
   - `src/main/java/tech/squadmc/squadmcor/squadmc.java`: добавлена строка
     `SpikeContent.register(bus);` сразу после `ModItems.ITEMS.register(bus);`.
   - `src/main/resources/assets/squadmc/lang/en_us.json`: добавлены названия SPIKE
     и сообщения о попадании. Остальные значения из присланного файла сохранены.
   Если ты уже менял эти два файла после отправки, перенеси указанные изменения
   в свою актуальную версию вручную. Если у тебя уже есть `ru_ru.json`, объедини его ключи.
3. Оставь в зависимостях проекта присланную сборку
   `Squad-superbwarfare-1.20.1-0.8.8-final-6a6b54795.jar` и совместимый GeckoLib.
   Из корня проекта выполни в PowerShell:

   ```powershell
   .\gradlew.bat build
   ```

4. Установи полученный JAR **squadmc** из `build/libs` на клиент и сервер вместе
   с SBW и его зависимостями. Используй одну версию `squadmc` на обеих сторонах.

Основной JAR SBW менять не требуется. Новые классы не добавляются внутрь SBW:
они компилируются как часть твоего `squadmc`.

## Проверка в игре

Выдай предмет и боеприпасы:

```mcfunction
/give @p squadmc:spike
/give @p superbwarfare:javelin_missile 16
```

Перезарядка — обычной клавишей SBW. Войди в прицел и удерживай **ЛКМ две
секунды**, пока горит SEEK. После выстрела ЛКМ можно отпустить: для наведения
нужно оставаться в прицеле и плавно перемещать его мышью. Выход из прицела
окончательно отключает управление уже выпущенной ракетой.

Проверь короткое нажатие и отпускание на 1,5 секунды: выстрела быть не должно.
Новое нажатие должно заново отсчитать полные две секунды. Задержка считается
сервером, поэтому при низком TPS фактическое время подготовки увеличивается.
После обновления поставь новую сборку и на клиент, и на сервер: версия
внутреннего сетевого протокола SPIKE изменена с 1 на 2.

Проверь поворот в полёте, выход и повторный вход в прицел, попадание рядом
с двумя целями и попадание в стену. Урон должна получать только задетая
ракетой цель, стена должна оставаться целой. На сервере проверь независимое
управление ракетами двух игроков.

Смена оружия, перезарядка, открытие меню, переход к виду от третьего лица,
смерть или отключение игрока также прерывают управление. Автоперезарядка
отключена, чтобы опустевшая пусковая установка не сбрасывала прицел сразу
после выстрела. При обычных 20 TPS ракета существует до 20 секунд.

## Что можно настроить

`entity/projectile/SpikeMissileEntity.java` содержит скорость, ограничение
поворота, время жизни, высоту траектории и `DIRECT_DAMAGE`. Изменяя урон,
обновляй также `Damage` в `data/squadmc/sbw/guns/spike.json`.
Для обычного урона с учётом брони нужно убрать соответствующие теги типа
урона из ресурсов; сейчас они обеспечивают заданные 1000.

В `verification` находятся независимые от Minecraft тесты сеансов управления
и задержки выстрела.
Итог выполненных проверок указан в `verification/RESULTS_RU.txt`.

Модели, текстуры и звуки SPIKE загружаются по ссылкам из SBW. В общем архиве
`SquadMC-with-SPIKE-all-files.zip` исходный JAR SBW лежит в `libs`, а все 318
файлов из TXT объединены с правками SPIKE. Недостающие скрипты сборки и
бинарные ресурсы самого squadmc нужно сохранить из твоего исходного проекта.
